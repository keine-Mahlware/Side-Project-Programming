Was ist eine SPS?

Eine SPS ist eine speicherprogrammierbare Steuerung und wird zur Automatisierung von Maschinen und Anlagen verwendet.

Typische Bestandteile einer SPS-Anlage

  • CPU
  • Sensoren
  • Aktoren
  • Ein- und Ausgabemodule
  • Netzwerk/Kommunikation
